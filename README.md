## 📖 About

This is the source code of my personal portfolio website, live at **[najmachaudhary.me](https://najmachaudhary.me)**.
It is built with plain HTML, CSS and vanilla JavaScript — no frameworks, no build step — so it loads fast and can be hosted anywhere.

## ✨ Features

- 🎨 **Unique crimson & amber theme** with animated aurora background and subtle grain texture
- 🌗 **Dark / Light mode** toggle (remembers your choice)
- 📱 **Fully responsive** — designed mobile-first, tested from 360px phones to large desktops
- 🖼️ **Crystal-clear project screenshots** shown at full resolution in browser-style frames
- 🔍 **Full-screen image viewer** — click/tap any project to open it, with keyboard arrows, swipe gestures and tap-to-zoom
- ⌨️ **Typing role animation**, scrolling tech-stack marquee and scroll-reveal animations
- 🧭 **Smart navigation** — floating navbar, active-section highlight, scroll progress bar and a full-screen mobile menu
- ♿ **Accessible** — semantic HTML, keyboard focus styles, ARIA labels and `prefers-reduced-motion` support
- ⚡ **Lightweight** — no dependencies to install, no build tools

## 🚀 Run Locally

No installation needed.

```bash
# 1. Clone the repository
git clone https://github.com/Najma-web-cell/Najma-web-cell.github.io.git
cd Najma-web-cell.github.io

# 2. Open index.html in your browser
#    or serve it locally:
npx serve .
# (or)  python -m http.server 8000
```

## ➕ Adding a New Project

1. Add your screenshot to the `images/` folder.
2. In `index.html`, copy an existing `<article class="project reveal">…</article>` block inside the **Featured projects** section.
3. Update the image path, title, description, tags and repository link.

The full-screen viewer picks up the new project automatically.

## 🌐 Deployment

The site is static and hosted on **GitHub Pages**:

1. Push changes to the `main` branch.
2. GitHub Pages rebuilds and publishes the site automatically within a minute or two.
3. The `CNAME` file keeps the custom domain **najmachaudhary.me** connected (DNS managed on Namecheap).

Prefer classic hosting? Upload all files to `public_html/` (so `index.html` sits directly inside it) and it works the same way.
